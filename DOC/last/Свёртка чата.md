## Важные решения / ловушки

1. CFL / «шахматы» на мобиле: `dt = Time.deltaTime * SimulationSpeed` 1. Du≈0.16 → dt≲1.2–1.5 на React. Desktop высокий FPS маскирует Speed; mobile нет. Fix (отложен): clamp dt в World. Разбор — `DOC/last/Techdebt.md` п.1b.

2. GS plane: XZ (`axisV=Z`), как Hybrid — не менять глобальный `InputRouter.planeMode`.

3. Density presence: Replace = `ClearField` → ClearAccum → Scatter → Normalize. Boost: `max(V, saturate(presence*gain))`.

4. ShouldDispatch для touch/agent — не делать в этих тикетах (сигнатура).

5. VFX Graph на мобиле = главный FPS-killer (Techdebt D/9) — отдельно от field debug.
