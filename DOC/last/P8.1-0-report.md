## Модель

Источники: `field_model_all.cpp` (режимы 0 и 7) и `boids_model_split_caps.cpp` (кап 48). Константы мира, числа частиц, радиуса диска и центров читаются из `M_WORLD`, `M_PERTEAM`, `M_DISCR`, `M_CX`. Без окружения режим 0 и режим 7, seed 1, `T=5.1`, совпали с прежним двоичным файлом побайтно. `M_LERP=1` читает `(1−φ)·prev + φ·cur`, `φ = (s mod K)/K`, до двух версий поля читается текущая версия. В README §4 добавлена строка: на устройстве шаг равен `simulationSpeed / FPS`, у P400c `simulationSpeed = 1`.

Матрица: seed 1…5, `T=15.1`, печать на t=1, 5 и 15. Все 24 конфигурации дошли до t=15. L не сокращался. Сцена S: мир 90, по 1500, диск 12, центры ±22, у режима 7 `G=90`. Сцена L: мир 180, по 12 000, диск 35, центры ±45, у режима 7 `G=180`. Кап 48 у split: множитель 4, режим аргумента 0.

В ячейке среднее по пяти seed и в скобках мин–макс. Контакт и чужие — проценты, как их печатает модель. Стаи — по командам (0 / 1). Шум курса печатает только `fm`; у split его нет.

### Чего таблица не показывает

1. Шум курса у капа 48: `boids_model_split_caps.cpp` его не печатает.
2. Разложение разницы S и L на число частиц, размер мира, радиус диска и центры. L меняет их вместе.
3. Цену на GPU и поведение на 400 000 частиц.
4. Выбор K и выбор интерполяции. Lerp в этих прогонах — запаздывание между двумя уже посчитанными версиями, не экстраполяция.
5. Поведение одного seed. Строка seed 1 не равна среднему пяти seed (это уже записано в README §9 для таблицы §7).
6. Поляризацию, плотности и разброс шума (`turnSd`): они есть в сырых файлах и в сводку не входили.
7. «Живость» стаи. Шум курса — модуль поворота за шаг при данном `dt`.
8. Кадры между t=5 и t=15. В таблицу попали только эти две отметки.
