## 2. Этап 2. Данные и эталон

1. `Assets/Scripts/Core/FieldNeighborSet.cs`: ресурс (`IDisposable`) с буферами `Raw` (6 `float` на тексель, ADR-061 §2.3), `Accum` (`uint`, 6 на тексель, создаётся только для Scatter), `Phi` (`float2` на тексель), `Field` (64 Б на тексель, ADR-061 §2.4), раскладка (`SpatialHashLayout` через `SpatialHashSet.ComputeLayout(center, extents, texelSize)`), число частиц, флаги `RefreshedThisFrame`, `Frame`. Размер сетки проверяется `SpatialHashSet.ValidateLayout`.
2. Маркерный интерфейс `IFieldNeighborPass` (рядом с `ISpatialHashConsumer`).
3. **C#-эталон** `Assets/Tests/Editor/FieldNeighborReference.cs` (только тесты): на `double`, по формулам ADR-061 §2.2–2.4: `Collect(positions, headings, teams, layout)`, `Convolve(raw, layout, R, interMultipliers)`, `Gradient(phi, layout)`. Эталон не использует GPU и код пассов. Он же даёт «сумма всех `N` = число частиц команды» и «сумма всех `H` = сумма курсов».
4. Тесты эталона самого по себе (без GPU): одна частица в центре текселя даёт `N=1` на одном текселе; в середине ячейки по 0,25 на четыре; на шве (позиция у края мира) веса уходят на противоположную сторону; `Σ N` по полю равно числу частиц; `Σ w_k·c_k = p` (сохранение первого момента, с учётом шва по минимальному образу); число смещений диска равно 25 при `Rt = 3`; `ψ(R) = 0`, `ψ` плоско внутри `r0`.
