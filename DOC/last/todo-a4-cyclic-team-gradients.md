## 1. Правки `M3DDemoTools.cs`

Только `CreateBoidsHashTwoTeamsAsset` и локальные методы градиентов рядом с `IceGradient()`.

1. Добавить `FireCyclicGradient()` и заменить тело `IceGradient()` ключами из раздела A4 ADR (5 ключей цвета на градиент, режим Blend, альфа 1 в `t = 0` и `t = 1`). Оба метода возвращают **новый** `Gradient` при каждом вызове (как `DefaultFireGradient`).

## 2. Тесты

Только в `BoidsHashTwoTeamsPresetTests.cs` (тест самого пресета, правка допустима). Остальные тестовые файлы не править.

1. **Обновить `Preset_MatchesTwoTeams`:** строки проверок цветов (`Evaluate(0f)`, `Evaluate(1f)`, `Evaluate(0.45f)` и т. д.) заменить проверками пяти ключей каждой команды (`t = 0, 0,25, 0,5, 0,75, 1`) в допуске `ChannelTolerance`.
2. **Новый тест `TeamGradients_AreCyclicAndReadable`** (или набор из нескольких, на ваш вкус). Для каждой команды 256 отсчётов `Evaluate(i / 255f)`:
   - концы совпадают в допуске `1/255` по каждому каналу (включая альфу);
   - для каждого отсчёта `Color.RGBToHSV`: `S ≥ 0,5`, `V ≥ 0,4`;
   - тон огня (градусы) в диапазоне `[0, 60]`, тон льда в диапазоне `[180, 250]`;
   - расстояние до `BackgroundLinear = (0.136, 0.120, 0.105)` в линейных RGB не меньше `0,25`. Константа с комментарием: «снимок Play 2026-10-10, фон `(103, 97, 91)` в sRGB»;
   - максимум относительной яркости `0.2126 r + 0.7152 g + 0.0722 b`: у огня на `t ∈ [0,45; 0,55]`, у льда на `t ≤ 0,05` или `t ≥ 0,95`.
3. Сообщения утверждений читаемые: какой отсчёт и какая команда провалились.
4. Если какое-то условие не выполняется на предложенных ключах, **не ослаблять порог**, а подобрать ключи в пределах ТЗ и записать это в ADR. Если подобрать не удаётся, остановиться и описать.

## 4. Play-проверка

1. Снимки «после» в тех же моментах: `play-a4-2teams-1s-after.png`, `play-a4-2teams-15s-after.png`.
2. Ледяная стая **без двухцветного крапа**; огонь без чёрных и почти белых точек. Раскладка в Play недетерминирована, сравнивать нужно палитру, а не положения.
3. **Сверка с кодированием sRGB на кадре около 1 с**, по моде насыщенных пикселей внутри габарита каждой стаи. Фон `(103, 97, 91)` и оттенки свечения исключить. Ожидание считать формулой sRGB (если `c ≤ 0,0031308`, то `12,92·c`, иначе `1,055·c^(1/2,4) − 0,055`, затем округление к байту), не по памяти. Лёд: яркий конец `(0,30, 0,80, 1,00)`. Огонь: пик `(1,00, 0,70, 0,10)`. Допуск ±4 на канал. Если мода плывёт из-за свечения, брать цвет изолированных частиц у края стаи. Тёмный центр льда отдельно не проверять.
4. **Подтверждение владельца:** вопрос в сдаче «ледяная стая без крапа?» Фазу A4 принимает только владелец.
