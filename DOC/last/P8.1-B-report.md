ТЗ просило одну проверку: 5 000 случайных частиц, velocity против `FieldRead` по double-полю `FieldNeighborReference`, допуск `max(2×10⁻⁴, 2×10⁻³·|F|)`. | Проверка | Результат | Предел |
| --- | --- | --- |
| velocity против `FieldRead` по `Field`, прочитанному с GPU после свёртки (Scatter) | максимум 1,21×10⁻⁶ | 1×10⁻⁵ абсолютно |
| Gather (хэш, сбор Gather, свёртка, сила) против double-эталона | максимум 3,09×10⁻⁶, за допуском ТЗ 0 / 5 000 | `max(2×10⁻⁴, 2×10⁻³·|F|)` |
| Scatter против double-эталона | максимум 1,52×10⁻³, за допуском ТЗ 23 / 5 000 (0,46%) | максимум не больше 3×10⁻³, доля не больше 1%. Подпись теста: «регрессионный предел по наблюдаемому разбросу фиксированной точки» |
