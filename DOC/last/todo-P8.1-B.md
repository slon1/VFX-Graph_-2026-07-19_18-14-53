## 2. Этап 2. Эталоны (C#, только тесты)

2. Тесты эталонов (без GPU): одна частица, `FieldRead` даёт `F = 0` (самовклад сокращается), `FullTraversal` тоже 0; две частицы одной команды на расстоянии 1: `FullTraversal` даёт ожидаемые знаки (`F_sep` отталкивает, `F_align` вдоль курса соседа, `F_coh` к соседу); две частицы разных команд: `F_sep` усилен на `inter`, `F_align` и `F_coh` равны 0; частицы по разные стороны шва тора ведут себя как рядом. `FieldRead` и `FullTraversal` совпадают на конфигурации, где поле точно (например, регулярная решётка частиц в текселях: допуск записать и обосновать).
