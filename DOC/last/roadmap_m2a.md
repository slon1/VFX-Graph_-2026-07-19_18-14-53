## 1. Общий план реализации (Roadmap, после M2a)

Цель фазы: превратить фреймворк из "particle+field pipeline с одним hybrid-примером" в **словарь переиспользуемых примитивов**, достаточный чтобы собирать разнородные семьи алгоритмов (boids-через-поле, Gray-Scott/reaction-diffusion, Lenia-подобные системы, particle-life) как комбинации пассов в `EffectAsset`, без написания новой инфраструктуры под каждую семью.

| Шаг               | Название                                                                                       | Даёт                                                                                               | Статус       |
| ----------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------ |
| M2a               | FieldSet + hybrid pipeline                                                                     | Read/WriteInPlace/WritePingPong, ping-pong swap, один hybrid demo                                  | ✅ готово     |
| M2a.1             | ClearFieldPass                                                                                 | Per-frame обнуление поля                                                                           | ✅ готово     |
| **M2b.1**         | **Generic P2G scatter (atomic)**                                                               | **Частица → поле, без гонок данных**                                                               | **✅ готово** |
| **M2b.1.1**       | **Generic field slot naming**                                                                  | **Фикс. `FieldRead`/`FieldWrite`; без `{fieldName}` в HLSL; guard unique field**                   | **✅ готово** |
| **M2b.2**         | **Gradient sample**                                                                            | **Поле → сила по ∇ (SampleGradientFieldPass)**                                                     | **✅ готово** |
| M2b.3             | Diffuse pass (box/gaussian stencil)                                                            | Blur поля — для flock-field, Gray-Scott-подобных реакций                                           |              |
| M2c               | Multi-field validation в `FieldKernelPass`                                                     | Гарантия, что пассы с несколькими полями (Gray-Scott U+V) не подставят чужой resolution/plane      |              |
| M2d               | Рендер: LUT-палитра + trail/persistence buffer                                                 | "Живой" вид вместо debug quad, независимо от алгоритма                                             |              |
| M2e               | PassGroup / SolverPreset                                                                       | Семьи алгоритмов включаются/выключаются одним элементом, не пересборкой 10-20 пассов               |              |
| M2f               | Exploration UX: reroll + Play-Mode snapshot-to-preset                                          | Быстрый цикл перебора параметров без потери находок                                                |              |
| M2g               | Специфичные примитивы: произвольная свёртка (Lenia), species/attraction matrix (Particle Life) | Открывает конкретные семьи из вдохновляющего списка                                                |              |
| M2h (опционально) | Эвристика "интересности" (дисперсия поля во времени)                                           | Ускоряет ручной/авто-перебор параметров, не аналитика                                              |              |

M2b.1 (этот документ) выбран первым шагом, потому что это единственный примитив из списка, без которого физически невозможно писать P2G-логику вообще (частица не может записать своё состояние в поле никаким иным способом), и он же — предпосылка для M2b.2/M2b.3 в частях, где они читают то, что было наскаттерено.
