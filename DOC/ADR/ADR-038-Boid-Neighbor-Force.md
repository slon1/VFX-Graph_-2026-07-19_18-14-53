## ADR-038: Сила соседей по снимку хэша

**Статус:** принято, EditMode зелёный (2026-10-03). Steer и пресета нет.
**Дата:** 2026-10-03
**Контекст:** M3D Framework, после P4 [ADR-037](ADR-037-Team-Profile.md). Зонтик — [ADR-034](ADR-034-Spatial-Hash-And-Teams.md). План — [`plan-Reynolds-Boids-v2.md`](../plan-Reynolds-Boids-v2.md) §2.3 и §P5. Это только приёмка 5a. Steer, пресет и Play — 5b и 5c. P2 не открывать.
**Не меняет:** кернелы хэша, `HeadingSteer`, `SwarmSource`, пробники `HashProbe_*`, палитру, `Boids_mk1`, Physarum, fluid.
**ТЗ:** [`todo-adr-034-p5a-neighbor-force.md`](../last/todo-adr-034-p5a-neighbor-force.md)

---

### Контекст

Хэш уже строит снимок `position` / `heading` / `teamId`. Список команд уже заливается в буфер из 8 слотов, но его никто не читает. Без силы буфер можно собрать с пустым списком: `context.Teams` остаётся `null`. Первый пасс, который привяжет этот буфер, на пустом списке упадёт уже в биндинге, а не в понятной ошибке сборки.

Радиус команды можно поменять в инспекторе во время Play. Проверка «радиус не больше ячейки» живёт только в Build. Если в Play выставить радиус больше ячейки, поиск по 3×3 перестанет видеть часть диска. Эти радиусы читает только сила, не steer.

`cruise` и `turn` в эту приёмку не входят. Их читает только `TeamHeadingSteer`, проверка знака и поведение `turn == 0` — ТЗ 5b.

### Решение

#### 1. Пустой список команд — ошибка сборки

Правило одно: включённый пасс, который читает `context.Teams`, требует `teams.Count > 0`. Иначе `InvalidOperationException` до создания буфера. В 5a в список входит только `BoidNeighborForcePass`. В 5b туда добавляется `TeamHeadingSteerPass`, сам текст правила не переписывается. Класс steer в 5a не создавать. Выключенный пасс список не требует.

#### 2. Радиус в Play проверяется снова

Build по-прежнему отвергает радиус больше `min(cell) * (1 + GridEpsilon)`. В `Update`, уже после заливки буфера команд и до пассов, та же проверка повторяется. Нарушение — одно предупреждение, пока числа не станут допустимыми. Мир не останавливать и исключение не бросать. Кернел радиус не режет: формула видит то значение, которое лежит в профиле. Множитель чужих по-прежнему не радиус.

Пока предупреждение висит, соседи за пределами 3×3 не находятся. Проверка об этом говорит, поиск сам не сужает.

#### 3. Соседи только из снимка

`BoidNeighborForce` прибавляет силу к `velocity`. Своя позиция и свой `teamId` читаются из живых буферов. Чужие позиция, курс и команда — только из `SortedPositions` / `SortedDirections` / `SortedTeams`. Живой `heading` сила не читает.

Индекс команды в кернеле силы — `min(teamId, 7)`. Слот за концом списка нулевой, сила из него нулевая. Частицу с чужим номером на последнюю живую команду не пересаживать. В 5b та же строка копируется в кернел steer: обращение к буферу там отдельное.

`struct TeamParams` в HLSL — те же три `float4` в том же порядке, stride 48. Это проверяет кернел, который читает слот назад, а не только `Marshal.SizeOf`.

#### 4. Кап — предохранитель, не эталон

`maxNeighbors == 0` значит без капа. Эталон CPU считается только в этом режиме. Кап считает посещённых соседей, не тех, кто прошёл по радиусу. Порядок девяти ячеек сдвинут на `id % 9`. Счётчик срабатываний по умолчанию выключен и тогда не трогает свой буфер.

### Отклонённые варианты

**Клэмп `min(teamId, count - 1)`.** Частица с битым номером начинает вести себя как последняя команда. Ноль в хвосте буфера честнее.

**Проверка радиуса в кернеле через `min(radius, cell)`.** Она прячет число, которое автор видит в инспекторе. Повторная проверка в Play оставляет число как есть и один раз говорит, что сетка его не покрывает.

**`SetVector4` в базовом классе.** Хэш уже умеет `PushParams`. Силе хватает его и `BindBuffer`.

**Энтропия и `dirSum`.** Это P8a. В сумму силы не входят.

### Последствия

- (+) Пустой список команд не доходит до биндинга.
- (+) Play-правка радиуса не проходит молча: один раз пишется предупреждение.
- (−) Пока радиус больше ячейки, сила всё ещё не видит соседей за 3×3. Предупреждение поиск не сужает.
- (−) Стаи на экране всё ещё нет: нет steer и нет пресета.
