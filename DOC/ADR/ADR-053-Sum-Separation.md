# ADR-053: сумма separation

**Статус:** записано по наблюдению владельца 2026-10-22.
**Дата:** 2026-10-22.
**Контекст:** M3D Framework, ветка `feature/reynolds-boids`. Сила соседей — [ADR-038](ADR-038-Boid-Neighbor-Force.md). Кап считает посещённые слоты и обрывает обход клеток — [ADR-052](ADR-052-Accepted-Neighbor-Cap.md).

## 1. Зачем

Принятая формула делит отталкивание на число соседей и берёт знаменатель `r² + 0,001`. Сплочение при этом единичный вектор к центру, умноженный на вес: его длина не зависит от размера стаи. При `maxNeighbors = 0` частица видит весь круг, среднее отталкивание остаётся порядка одного соседа и проигрывает сплочению. Стая схлопывается в точку. Близкий сосед не спасает: его большой вклад тоже делится на всех в радиусе.

Старая симуляция отталкивание суммировала: `d / (dist² + 0,01) * pressure`, без деления на число соседей. На краю полного круга сумма растёт с числом соседей и держит сплочение на размере в метры. Режим добавляет эту формулу переключателем. Принятое среднее остаётся значением по умолчанию.

## 2. Как работает

Галка **Sum Separation** на `BoidNeighborForcePass`, каждый кадр уходит в ядро как `SeparationSum`. Одинаково для `walk 0`, `walk 1` и `walk 2`. Выравнивание и сплочение не меняются.

| Галка | Отталкивание |
| --- | --- |
| выкл | `(sep / sepN) * weight`, знаменатель `r² + 0,001` |
| вкл | `sep * weight`, знаменатель `r² + 0,01` |

`sep` — сумма по соседям в радиусе separation: `−d / (r² + ε)`, чужой сосед ещё умножен на `interGroupSeparationMultiplier`.

## 3. Эффект при `maxNeighbors = 0`

Ноль не обрывает обход: частица читает девять клеток и всех в радиусе. В середине стаи толчки гасятся. На краю сумма смотрит наружу и по длине сравнивается со сплочением. Получаются устойчивые крупные стаи.

Наблюдение на `Boids_hash_2teamsSumSep`: радиусы 9, ячейка 9, веса separation 0,75 / alignment 3 / cohesion 2, чужие ×2, галка включена, `maxNeighbors = 0`.

Любой положительный кап обрывает обход на первых клетках, противоположная сторона не прочитана. Сумма остаётся вдоль оси решётки и длиннее выравнивания, стая рвётся на линии. То же среднее при нулевом капе стаю не держит: краевой толчок снова короче сплочения.
