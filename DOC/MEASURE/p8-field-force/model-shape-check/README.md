# Модель формы стай (numpy), проверка 2026-11-05

Упрощённая модель, **не движок**: float64, 3000 частиц (2 × 1500, диски R = 12, центры ±22, мир 90 м), R = 3, веса 1,2 / 0,8 / 0,6, множитель чужих 4, cruise 6, turn 4, 60 кадров/с. Курс обновляется как `h ← unit(lerp(h, unit(F), min(turn·dt, 1)))`, позиция `p += h·cruise·dt`. Поле: CIC-сбор, диск из 25 текселей, `ψ = ½ ln((max(d, r0)² + ε)/(R² + ε))`, центральная разность, формулы силы ADR-062 §2.2. Эталон: точный обход (`cKDTree`, минимальный образ).

Абсолютные числа с движком не совпадают (плотность стай около 12 на м² против 19–31 в README P8.1-0). Сравнивать можно только варианты между собой.

Файлы: `sim.py` (модель и метрики), `sim2.py` (варианты: тексель 0,5 и 0,25, меньшее ядро, гибриды), `sim3.py` (ориентация линий, поворот старта), `sim4.py` (окно точного разделения). Запуск: `python3 sim.py field 1`, `python3 sim2.py hyb_sepexact 1 5`, `python3 sim3.py 30`, `python3 sim4.py 1.5`.

Ориентация линий (`sim3.py`, поле, K = 1): при старте вдоль оси x на t = 2 с 79% линий лежит в пределах 10° от осей сетки, при повороте старта на 30° 7%; на t = 5 с во всех вариантах 14–19% (случайных 22%). В модели линии идут вдоль курса, а не вдоль осей решётки.

Метрики: «линейная окрестность» = у частицы в выборке (в неё входит сама частица, её смещение нулевое) не меньше 6 точек, то есть не меньше 5 других своих в R, и `sqrt(λ_min/λ_max)` выборочной ковариации (`np.cov`, вычитание среднего, `ddof = 1`) смещений меньше 0,25. Сосед в R у модели `r ≤ R` (`cKDTree`), у зонда `r² < R²`; на непрерывных данных разницы нет. Занятые клетки = число различных `floor((p − origin)/1 м)` по всем частицам.
